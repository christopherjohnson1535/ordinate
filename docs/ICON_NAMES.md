# Icon names

Ordinate names its icons in its own words: what an icon means here, in plain English. The artwork did not change.

The old names still work until the next major version. `Icon` draws the renamed icon and warns once in the console, and an `IconProvider` keyed by an old name still replaces the icon. Use the new names in new code.

Status icons are named for the condition they mark, so the same words appear in StatusIndicator, Alert and the code editor's status bar: `complete`, `caution`, `fault`, `note`, `underway`, `waiting`, `halted` and `queued`. Solid variants end in `-solid`, and the assistant icons use `assist`.
